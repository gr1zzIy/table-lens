# TableLens — коротка інструкція

TableLens переглядає та редагує локальні DBF, CSV, TSV і JSON. Він працює на Windows, macOS і Linux та не надсилає вміст таблиць у мережу.

## Запуск

Потрібен .NET 10 SDK, якщо запускаєте вихідний код:

```bash
dotnet run --project src/TableLens.Desktop
```

Для готової self-contained збірки .NET окремо не потрібен. Архів застосунку містить виконуваний файл, бібліотеки, довідник і приклади. Зберігайте їх разом. Для macOS скрипт підготовлює `.app`; публічні релізи потребують підпису розробника та notarization.

## Файли та проєкти

- **Відкрити файли** або **Відкрити папку** замінює поточний список таблиць.
- **Додати файли**, кнопка **+** і перетягування доповнюють список.
- Папки переглядаються рекурсивно, включно із вкладеними.
- **Прибрати зі списку** і **Очистити список** змінюють лише робочу область; файли залишаються на диску.
- Працювати можна без проєкту. **Проєкт → Новий проєкт** створює порожню іменовану область.
- **Зберегти проєкт** запам'ятовує список і параметри читання у `.tablelens.json`. Дані таблиць зберігаються окремою командою.
- Перед закриттям або зміною проєкту програма пропонує зберегти зміни списку. Після закриття проєкту можна знову відкривати довільні файли.
- Останній збережений проєкт відновлюється під час наступного запуску. Старі WinForms-проєкти з `Name` / `FilePaths` відкриваються тією ж командою.

## Перегляд і фільтри

Зліва — файли, справа — **Дані**, **Структура** та **Інформація**. Повний шлях показується у підказці над назвою папки та на вкладці інформації. Ширина й порядок колонок запам'ятовуються для кожного файла.

Поле пошуку переглядає всі колонки. Під кожним заголовком є окремий фільтр:

| Приклад | Дія |
| --- | --- |
| `Київ` | Містить текст |
| `==Київ` | Дорівнює значенню |
| `!Київ` | Не містить текст |
| `!=` | Непорожнє значення |
| `==null` | Порожнє або NULL |
| `=="null"` | Саме текст `null` |
| `>10` / `<=100` | Порівняння чисел або дат |
| `==Київ or ==Львів` | Будь-яка з двох умов |

Різні колонки поєднуються через AND. У CSV числові текстові колонки порівнюються як числа, але початкові значення, зокрема `000123`, залишаються текстом. Для колонок із нечисловим текстом діє текстове порівняння. Помилка фільтра відображається внизу; останній коректний результат залишається на екрані.

Клік по назві колонки сортує, повторний клік змінює напрям. **Скинути** прибирає пошук і фільтри. `Ctrl+C` / `⌘C` копіює вибрані рядки; контекстне меню дозволяє копіювати поточну клітинку.

## Редагування

1. Натисніть **Редагувати**.
2. Для простих значень двічі клацніть клітинку. Для кількох полів або вкладеного JSON відкрийте **Редагувати рядок**.
3. За потреби додайте або видаліть рядки. У редакторі рядка порожній текст відрізняється від позначки **NULL**.
4. Використовуйте **Скасувати**, **Повторити** та **Історія змін**.
5. Натисніть **Зберегти**. До цього зміни зберігаються в пам'яті.

Перед перезаписом створюється резервна копія `.bak`. Якщо інша програма змінила оригінал, збереження блокується: можна експортувати свої зміни під іншою назвою. Перемикання файла та закриття застосунку запитує про незбережені зміни.

Редагування DBF підтримує dBase III без memo, з полями Char, Numeric, Float, Date і Logical. Memo/DBT, FoxPro, повторювані назви полів і пошкоджені/частково прочитані таблиці залишаються для перегляду. Їх можна експортувати в CSV/JSON. Число, яке не вміщується у поле, надлишкова точність чи текст, який не можна записати у вибраному кодуванні, не обрізається: програма показує помилку й залишає оригінал.

## CSV та JSON

**Налаштування → Параметри імпорту** дозволяє змінити кодування, роздільник CSV, наявність заголовка і поле JSON з масивом. Параметри застосовуються після перечитування вибраного файла і використовуються для нових файлів.

JSON підтримує масив об'єктів, одиночний об'єкт або об'єкт із масивом записів. Вкладені значення зберігаються як JSON, а метадані навколо масиву залишаються під час збереження. Якщо є кілька масивів, укажіть потрібне поле, наприклад `records`. Одиночний об'єкт залишається одним рядком. Масиви простих чисел чи рядків не підтримуються як таблиця.

**Експорт** записує всі або відфільтровані рядки в окремий файл. CSV має UTF-8 і текстові значення; JSON зберігає типи. Експорт у DBF доступний для DBF-джерел. Нова порожня JSON-таблиця записується як `[]`: формат не зберігає схему порожнього масиву.

## Структура і довідник DBF

На вкладці **Структура** видно фактичні та відсутні очікувані поля. У режимі редагування **Змінити структуру DBF** дозволяє змінити типи, довжини, десяткові знаки, додати чи прибрати поля. Для перейменування зберігайте початкову назву в колонці **Джерело**. Зміни структури також мають Undo/Redo.

**Довідник DBF-полів** змінює описи, замінює еталон фактичною структурою або прибирає відсутні поля з еталона. Довідник лежить у користувацькій папці даних TableLens, а не поряд з EXE. При першому запуску туди копіюється базова конфігурація; перед зміною створюється `.bak`.

**Інструменти → Порівняти структури файлів** працює з двома таблицями. **Порівняти папки DBF** рекурсивно знаходить DBF, зіставляє відносні шляхи, унікальні назви та відомі маски. Неоднозначні відповідники позначаються для ручної перевірки.

## Оформлення

У налаштуваннях є системна, світла та темна теми. Тема змінюється одразу; українська/англійська мова інтерфейсу — після перезапуску.

Таблиці завантажуються в пам'ять. Для дуже великих файлів обсяг доступної RAM визначає практичне обмеження; це настільний редактор, а не рушій бази даних.
